# Permit portal reference screenshots

- `ready.jpg`: ready for delivery; the portal says an SMS will specify when and where to collect the permit.
- `in-work.png`: processing result.
- `not-found.png`: no record found.

These screenshots document the portal's appearance and wording. They do not
establish its HTML structure. The ready-message test in `../status.test.ts`
uses text manually transcribed from `ready.jpg`; it does not perform OCR.
